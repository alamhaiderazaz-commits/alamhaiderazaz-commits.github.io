Privacy Policy

Last Updated: October 2026

1. Introduction

This privacy policy governs the private YouTube automation application ("Application") developed and maintained by the owner. The application operates as an internal backend utility for publishing content and monitoring analytics for the owner's personal channel.

2. Data Access & Scopes

The Application accesses Google APIs solely to interact with resources owned directly by the application developer:

  • Google Drive: Accesses media files, project assets, and metadata authored by the channel owner. No external user files are read or processed.
  • YouTube Data API & Analytics API: Creates and uploads video entries, manages video descriptions, and retrieves view metrics specifically for the owner's personal channel.

3. Third-Party Data & Storage

The Application does not collect, sell, lease, or store any personal data or credentials of third-party users. It is an unlisted internal tool that does not offer public user registration or third-party authentication services.

4. Data Retention & Security

All authentication tokens are secured directly within encrypted cloud secret stores. No private secrets or customer identifiers are exposed or retained beyond required runtime operations.
